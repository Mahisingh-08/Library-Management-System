# Library Management System

## 1. Project Title

Library Management System

## 2. Project Overview

The Library Management System is a simple Python-based project developed as part of the Python Essentials course.

The project helps manage basic library activities such as books, students, issuing books, returning books, and viewing library reports.

The project is designed using basic Python concepts such as lists, dictionaries, strings, loops, conditional statements, functions, and tuples.

## 3. Features

The project provides the following features:

1. Add a new book
2. View all books
3. Search for a book
4. Add a student
5. View students
6. Issue a book
7. Return a book
8. View library report
9. Exit the program

## 7. Requirements

Python 3 or a newer version of Python 3 is required to run this project.

No external Python libraries are required.

## 8. How to Run the Project

### Step 1: Install Python

Install Python 3 on your computer.

### Step 2: Open the Project

Open the Library-Management-System folder in Visual Studio Code.

### Step 3: Open the Terminal

In Visual Studio Code, open:

Terminal → New Terminal

### Step 4: Run the Program

Enter the following command:

```text
python main.py
```

### Step 5: Use the Menu

The program will display a menu:

```text
1. Add Book
2. View Books
3. Search Book
4. Add Student
5. View Students
6. Issue Book
7. Return Book
8. Library Report
9. Exit
```

Enter the number of the operation you want to perform.

## 10. Limitations

This is a beginner-level project.

The project currently stores data while the program is running. The data is not permanently stored after the program is closed.

The project does not use a database or graphical user interface.

## 11. Conclusion

The Library Management System demonstrates how basic Python concepts can be used to create a simple real-world application.

The project provides basic library operations through a command-line interface and was developed using concepts covered in the Python Essentials course.
