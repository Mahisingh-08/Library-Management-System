# Project Statement

## Project Title

Library Management System

## Problem Statement

Managing books and student records manually can take time and can lead to mistakes. A simple computer-based system can help manage basic library activities in an organized way.

The Library Management System provides a simple command-line solution for managing books, students, and book issue and return activities.

## Objective

The main objective of this project is to create a simple library management system using basic Python programming concepts.

The project aims to:

* Add and view books.
* Search for books.
* Add and view students.
* Issue books to students.
* Return books.
* Display a basic library report.
* Handle invalid menu choices.

## Target Users

The system is designed for:

* Small libraries
* Students learning Python
* Beginners who want to understand how Python can be used for a real-world application

## Main Modules

### 1. Book Management

This module allows the user to add books, view books, and search for a book.

### 2. Student Management

This module allows the user to add students and view student records.

### 3. Issue and Return Management

This module allows the user to issue an available book to a student and return an issued book.

### 4. Library Report

This module displays the total number of books, available books, issued books, and students.

## Scope

The current version of the project focuses on basic library operations through a command-line interface.

The project does not include a database or graphical user interface. Data is stored using Python data structures while the program is running.

## Expected Outcome

The expected outcome is a simple and easy-to-use command-line library management system that demonstrates the practical use of basic Python concepts.
